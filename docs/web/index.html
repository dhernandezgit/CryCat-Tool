Cargando el motor…
Sube tus imágenes y pulsa Colocar de forma óptima. CryCat calcula la silueta real de cada dibujo (no la caja), las encaja en el área recortable de la Cricut y te da un PNG a 300 ppp listo para imprimir. Tus imágenes no salen de tu equipo: el motor se ejecuta en el navegador con el mismo código que la aplicación de escritorio.
En el navegador el cálculo es más lento que en el ejecutable: para muchas piezas usa calidad Rápida o menos copias (el resultado puede quedar parcial si se agota el tiempo).
